# Security policy

## Supported versions

Security fixes go into the next release. Only the latest release on
[PyPI](https://pypi.org/project/crosstl/) is supported.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/CrossGL/crosstl/security/advisories/new),
not in a public issue or pull request. Include the CrossTL version, the
command or API call, and the smallest input that reproduces the problem.

Maintainers aim to acknowledge a report within a week, agree a disclosure
date with you, and credit you in the advisory unless you prefer otherwise.

CrossTL reads and writes source files and can run the validators and
compilers installed on your machine. Bugs where translated output is wrong
but harmless are ordinary bugs; please file those as issues.

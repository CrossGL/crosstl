Metal output binds a sampler for each combined sampler (`sampler2D`, `samplerCube`, ...) that a CrossGL stage block declares, as it already did for program-scope ones, so the entry point takes `sampler <texture>Sampler [[sampler(n)]]` and samples with the host's sampler state. It used to sample through an inline `sampler(mag_filter::linear, min_filter::linear)`, which ignores the host's filtering and address modes.

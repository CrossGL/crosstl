Rust output reads and writes a workgroup scalar, vector, matrix or structure through the `&mut T` reference rust-gpu declares it with, as `(*name)`, and passes the reference itself to the helpers that use it. It used to read the reference as a value (`s.v + a0` with `a0: &mut f32`, which rustc rejects) and to assign `a0 = &mut 1.0`, which rebinds the parameter instead of writing the shared memory. Workgroup arrays still index the reference directly.

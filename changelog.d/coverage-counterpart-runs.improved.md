Coverage runs more compute probes on a GPU. An output-row probe whose CrossGL probe calls a counterpart overload, such as Metal's `atomic_fetch_add_explicit` written as CrossGL's `atomicAdd`, now runs against the native probe when both calls read the same input elements and store the same kind of result. Compute constructs that read no input, such as `local-invocation-id` and `subgroup-size`, now declare an unread input as function probes do, so the conformance harness runs them in the input and output rows.

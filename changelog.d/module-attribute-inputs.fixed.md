HLSL, MSL, Slang and Rust output pass a module-scope stage input or output written with the `@input` or `@output` attribute (`float3 position @input @location(0);`, as the SPIR-V and GLSL importers write it) through the entry point's interface structure, as they already did for the `in`/`out` qualifier form. Before, HLSL and Slang declared it as a uniform and MSL as a zero constant, so the stage read zero.

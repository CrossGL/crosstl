OpenCL C input imports work-item queries whose dimension is a runtime value as a bounds-checked read, `(u32(d) < 3u ? gl_GlobalInvocationID[u32(d)] : 0u)`, with 1 as the out-of-range value of the size queries, as the OpenCL C specification defines. A constant dimension of 3 or more folds to that value. `get_global_linear_id`, `get_global_offset` (always 0, because no CrossGL target passes a global offset) and `get_enqueued_local_size` (the work-group size) are imported too. `get_work_dim` and a dimension with a side effect are refused with `project.translate.opencl-work-item-unsupported`. The importer used to copy these calls unchanged, and the CrossGL parser then refused them as undeclared functions.

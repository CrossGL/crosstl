A translation that selects one CUDA, HIP or OpenCL C kernel (`entry_point=`) no longer refuses undeclared host-side names such as `getLastCudaError` or `rand` in functions the kernel never reaches: the undeclared-name checks now count function-form kernels (`@compute fn`) as stage entries, as the OpenGL generator already did when it dropped those functions. Whole-program translations still refuse such names.

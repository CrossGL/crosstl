HIP input reads `powif` and `powi` as CrossGL `powi`, HIP output writes `powi` as `powif` for a `float` base and `powi` for a `double` base, and CUDA output, whose library has no integer power, writes it as the double-precision `pow` with the exponent converted to `double`. HIP input and output refused both functions as undeclared. Other targets refuse `powi` with a diagnostic, and a vector base is refused.

GLSL output declares an unqualified module-scope variable that the program writes (a WGSL `var<private>`) as a private global instead of a `uniform`, which GLSL cannot store to; redeclares `gl_ClipDistance` and `gl_CullDistance` with their size when a stage structure names the whole distance array, so the array can be assigned and read whole; and writes the `nointerpolation` and `linear_*` interpolation spellings (Slang entry parameters) as `flat`, `centroid`, `sample` and `noperspective` instead of dropping them.

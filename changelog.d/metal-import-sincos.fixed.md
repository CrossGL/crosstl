Metal input: `sincos(x, cosval)`, including `fast::sincos` and `precise::sincos`, now imports as a CrossGL helper that stores the cosine and returns the sine, called where the source called `sincos` and evaluating `x` once. The two-operand call used to be copied into CrossGL unchanged, so HLSL and Slang output carried a call DXC and slangc reject, and GLSL, SPIR-V, WGSL and CUDA output refused the kernel. `double` operands are refused with `project.translate.metal-sincos-unsupported`.

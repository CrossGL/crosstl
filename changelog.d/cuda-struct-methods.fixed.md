CUDA input imports a member function defined in a struct body as a free function named `<Struct>_<method>` that takes the receiver as its first parameter, `inout` when the function writes a data member, and rewrites each member call to call it. A call of a member function the importer does not import, such as a constructor, an operator, a template, a static, virtual or out-of-class member function, or a member of a struct template, is refused. The importer used to drop every member function, so the translated program called a member that no target declares.

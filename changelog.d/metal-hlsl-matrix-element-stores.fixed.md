Metal output stores one element of an HLSL structured-buffer or constant-buffer matrix, `outp[i].m[1][0] += 0.25;` or `mats[i][0].y = v;`, by writing the word that holds the element in place, at the index the matrix's `_store` helper gives it, instead of refusing the store because the matrix is held as words. Row-major members, elements of matrix arrays and run-time indices are covered; a store to a whole column of such a matrix is still refused.

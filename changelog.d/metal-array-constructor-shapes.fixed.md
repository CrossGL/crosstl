Metal, HLSL and SPIR-V output build an array constructor with several dimensions, `float[2][2](float[2](1.0, 2.0), ...)`, or one sized by a named constant, `float[N](...)`, as an initializer list, where Metal and HLSL output used to keep the constructor, which their compilers reject, and the SPIR-V generator refused it (#3679, #3553). A short constructor outside a declaration, `a = float[3](1.0);`, is built in a full-size local whose list zero-fills the rest, as a declaration does, instead of being refused; one with more elements than its size is still refused (#3639).

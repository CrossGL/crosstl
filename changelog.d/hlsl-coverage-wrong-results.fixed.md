HLSL output now fills in the default arguments of helpers declared inside a stage block, writes the depth semantic a conservative depth layout promises (`SV_DepthGreaterEqual`, `SV_DepthLessEqual`), marks the payload of `hit.TraceRay(...)` and `hit.Invoke(...)` as `[raypayload]`, returns a typedef'd array as its lowered type, and builds a structure-lowered array return through a constructor function. A `@row_major` buffer member is laid out by rows, so a layout HLSL shares is declared as it is and a different one is refused. The HLSL importer keeps the direction of `SV_DepthGreaterEqual` and `SV_DepthLessEqual`, keeps the scalar texel type of a `GatherRaw` texture, and no longer writes `-(-x)` as `--x`.

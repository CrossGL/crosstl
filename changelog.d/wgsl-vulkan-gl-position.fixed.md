WGSL output lowers a vertex shader that writes `gl_Position` directly in a void entry point, as the Vulkan GLSL importer emits (`void main() { gl_Position = ...; }`), to a `@builtin(position)` field of a synthesized `VertexOutput` struct. Every reference shape keeps working — a whole write, a component write such as `gl_Position.y = -gl_Position.y`, a read such as `gl_Position.z / gl_Position.w`, and writes with an early `return` under `if`, loop and `switch` control flow — because the builtin is lowered to a local that is copied into the output at each return and at the fall-through end of the body. It used to refuse the shader with `WGSL target does not support implicit builtin identifier(s) in vertex stage: gl_Position`. A vertex output builtin with no WGSL modelling on this path, such as `gl_PointSize`, is rejected with a typed error that names it rather than emitted as an undefined identifier.

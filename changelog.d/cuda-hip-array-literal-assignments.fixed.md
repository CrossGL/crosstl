CUDA and HIP output assign a brace list to an array declared earlier, as the SPIR-V importer writes a stored constant array (`values = {1.0, 2.0, 4.0, 8.0};`), without assigning the C++ built-in array, which NVCC and hipcc rejected. A list of constants that names every element is stored element by element; any other list initializes a temporary array that is then copied, so its elements are evaluated once, an element that reads the target reads its old value, and elements a short list leaves out are value-initialized.

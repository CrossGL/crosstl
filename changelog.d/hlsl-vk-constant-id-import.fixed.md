HLSL input reads `[[vk::constant_id(N)]]` on a global as a specialization constant with its initializer as the default, as DXC's SPIR-V back end compiles it. Since #5014 the importer had made such a global a `$Globals` member and dropped its initializer, so GLSL output declared a loose `uniform`, SPIR-V output an `OpSpecConstant` of 0 and HLSL output a `$Globals` member. A constant DXC rejects (no default, `static`, not a scalar) is refused.

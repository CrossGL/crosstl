CUDA and HIP output fold file-scope matrix constants into statically initialized `__device__` matrices (the matrix helpers' component constructor is now `constexpr`), fold a scalar constant that reads a vector, array or matrix constant to a literal, and refuse a scalar or matrix constant whose initializer calls a function they cannot evaluate. A folded float component of FLT_MAX no longer stops generation with an `OverflowError`. nvcc and hipcc used to reject the output of these programs.

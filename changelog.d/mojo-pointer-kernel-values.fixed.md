Mojo input imports ``stack_allocation[N, T, address_space=AddressSpace.SHARED]()`` as a CrossGL workgroup array, ``Array[T, N]`` and ``InlineArray[T, N]`` as CrossGL arrays and ``value.copy()`` as the value. In a pointer kernel it refuses, by name, a method of a local value, a parameterized call and any other ``stack_allocation`` instead of writing Mojo text into CrossGL. Mojo output writes a workgroup array declared in a compute entry's body as a shared ``stack_allocation`` (it was a thread-local ``StaticTuple``), passes a module-scope value only to functions that read it where no parameter or local of that name is in scope, and refuses a member access that could be a structure field or a swizzle of a value of unknown type.

Slang output now reorders the arguments of a CrossGL `select(false_value, true_value, condition)` call to Slang's `select(condition, true_value, false_value)`. It used to write the call unchanged, so the program computed the wrong value without any error. Calls whose condition type is known still go through the `mix` helper, and every other non-user `select` is now reordered directly. A user-defined function named `select` is left alone (#4524).

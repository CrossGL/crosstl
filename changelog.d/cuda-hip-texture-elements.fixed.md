CUDA and HIP input import each texture fetch with the element type it returns: `tex1Dfetch<float>` and `tex2D<int>` give a scalar, an integer fetch reads an `isampler*` or `usampler*`, and a texture reference takes the element and read mode of its declaration. `tex1Dfetch` reads a texel buffer (`samplerBuffer`), as linear memory is, instead of a 1D texture at mip level 0, so Metal, HLSL, GLSL and SPIR-V output declare `texture_buffer`, `Buffer` and `samplerBuffer`. A texture object passed to a helper takes the type of the helper's fetch.

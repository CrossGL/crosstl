OpenCL C input writes `cross` on `float4` or `double4` vectors as `vec4(cross(a.xyz, b.xyz), 0.0)`, the zero-`w` result OpenCL defines. This includes arguments that are arithmetic, four-component swizzles or built-in calls such as `normalize(x)` and `cross(x, y)`, as in `cross(p1 - p0, p2 - p0)`. It used to copy the four-component call into CrossGL, where `cross` takes three components, so DXC rejected the HLSL output (#2867).

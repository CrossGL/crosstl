HLSL, Metal, Slang and WGSL output pass the stage built-ins a helper reads (`gl_LocalInvocationID`, `gl_FrontFacing`, `gl_VertexID` and the rest) to the helpers of a function-form entry (`@compute fn`), as they already did inside a stage block. The CUDA, HIP, OpenCL C and Mojo imports write their kernels that way, so a `__device__` helper that reads `threadIdx` no longer keeps the bare name, which DXC and the Metal compiler reject as undeclared.

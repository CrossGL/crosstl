Metal output converts the result of `sign`, `abs` and `step` to the type it is stored in (an `int2` initialized from `sign(float2)` now gets `int2(...)`), lowers `sign` of an integer value to a helper because Metal's `sign` has no integer overload, spells functions, locals and parameters declared through a typedef of a C array as Metal arrays, and keeps `__restrict` on the byte views of restrict buffer blocks.

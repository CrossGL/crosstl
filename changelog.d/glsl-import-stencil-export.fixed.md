GLSL input keeps a fragment shader's colour outputs as `out` declarations when `main` also writes `gl_FragStencilRefARB` (GL_ARB_shader_stencil_export), as it already did for `gl_FragDepth` and `gl_SampleMask`. Such a shader now translates to Metal (`[[stencil]]`), HLSL (`SV_StencilRef`) and Slang instead of being refused for mixing a returned colour with a stage-level stencil write, and a shader that writes only the stencil reference no longer gains an unwritten colour output.

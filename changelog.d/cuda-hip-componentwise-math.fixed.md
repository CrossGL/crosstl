CUDA and HIP output now compile the programs Metal, GLSL, HLSL, SPIR-V and Slang import with C math functions on vectors: `acosh`, `asinh`, `atanh`, `log10`, `rint`, `fabs`, `ilogb`, `copysign`, `fdim`, `fmax`, `fmin`, `fmod`, `nextafter` and the other one- and two-operand math library functions apply the `float` or `double` function to each component (a scalar operand applies to every component), since CUDA and HIP declare them for scalars only. `bitCount` of a vector returns `int` components, as GLSL defines it; a vector initializing or assigned to a vector of another component type is converted per component, as GLSL converts it implicitly; `int8`, `uint8`, `int16`, `uint16` and `float16_t` constructor casts become `static_cast` and `__float2half`; `vec4{}` becomes a zero vector; a `case` that declares a variable gets its own block, so two cases can declare one name; and SPIR-V's subgroup built-in inputs (`gl_SubgroupSize`, `gl_SubgroupInvocationID`, `gl_SubgroupID`, `gl_NumSubgroups`) are written as their `warpSize` expressions instead of uninitialized host globals.

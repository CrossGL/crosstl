GLSL output writes the case labels of a 32-bit `int` or `uint` switch in the selector's type (`case 4294967295u:` instead of an `int64_t` literal), converts `uint` offsets and bit counts of `bitfieldExtract` and `bitfieldInsert` to `int`, and reads a component of a vector element of a module-scope shared array as `tile[1][1]` instead of adding the component index to the element index. It refuses `cross` of operands that are not 3-vectors and double-precision operands of the trigonometric, hyperbolic and exponential functions, which GLSL declares for `float` only. glslang used to reject the output of each of these programs.

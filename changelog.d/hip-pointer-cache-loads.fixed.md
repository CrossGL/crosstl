HIP input imports a load cache intrinsic whose argument is a pointer, such as `__ldg(p)` or `__ldg(p + i)`, as the load `*(p + i)`, as CUDA input already does. It was refused with "CrossGL loads take one address", and only the `&p[i]` form was accepted. The same holds for `__ldca`, `__ldcg`, `__ldcs`, `__ldlu` and `__ldcv`, and a call with more than one argument is still refused (#4685).

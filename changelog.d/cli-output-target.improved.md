`crosstl shader.metal -o shader.hlsl` writes HLSL: without `--backend`, the single-file command takes the target from the output file's extension (`.hlsl`, `.metal`, `.glsl`, `.webgl.glsl`, `.spvasm`, `.wgsl`, `.cu`, `.hip`, `.slang`, `.rs`, `.mojo`, `.cgl`, and GLSL stage extensions such as `.frag` and `.comp`). It used to write CrossGL whatever the output file was called. `--backend` still wins, and without `-o` the command still writes CrossGL.

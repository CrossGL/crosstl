GLSL output keeps the ordering of rasterizer-ordered resources (`RasterizerOrderedBuffer`, `RasterizerOrderedTexture2D`, CrossGL `@rasterizer_ordered`). The fragment stage now declares `layout(pixel_interlock_ordered) in;`, requires GL_ARB_fragment_shader_interlock and brackets `main()` with `beginInvocationInterlockARB()` and `endInvocationInterlockARB()`, as DXC does for SPIR-V. The output used to drop the ordering, so overlapping fragments raced on the resource (#4307). A fragment `main()` that returns early is refused, because the extension allows the critical section only outside control flow and before any return.

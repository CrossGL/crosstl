GLSL output carries every CrossGL `atomicThreadFence` except one of system scope with the narrowest GLSL memory barrier that covers its memory and scope (`memoryBarrier`, `memoryBarrierBuffer`, `memoryBarrierImage`, `memoryBarrierShared`, `groupMemoryBarrier`), so sequentially consistent Metal atomics, which the Metal importer writes between two device-scope fences, translate into GLSL and GLSL ES instead of being refused.

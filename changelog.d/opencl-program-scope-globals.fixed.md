OpenCL C input refuses a writable program-scope variable in the global address space (`global int counter = 3;`, an unqualified one, or a function-scope `static` one) with the diagnostic `project.translate.opencl-global-variable-unsupported`. Every work-item shares that variable, and the importer used to write it as a module-scope CrossGL `var`, one copy per invocation, so a write made by one work-item never reached the others. `const` and `__constant` variables keep their import.

HLSL input imports `class` definitions and forward declarations as structs, as HLSL gives both keywords the same meaning; a program that declared a class used to fail with an undeclared type. A `void` function with a parameter semantic that runs `discard` or `clip` and writes no `out` parameter imports as a pixel entry point (a depth-only pass), so GLSL output no longer refuses it and Metal output no longer writes an invalid entry.

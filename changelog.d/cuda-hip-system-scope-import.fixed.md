CUDA and HIP input import system-scoped atomics (`atomicAdd_system` and the rest), CUDA `__syncwarp(mask)`, `clock`, `clock64`, HIP `wall_clock64` and initialized `__device__` variables instead of refusing them. CUDA and HIP output write the system-scoped atomics and `__syncwarp` back, every other target refuses them with a diagnostic, and HIP output performs `atomicInc_system` and `atomicDec_system`, which HIP does not declare, with an `atomicCAS_system` loop. `clock_t` is a 64-bit integer.

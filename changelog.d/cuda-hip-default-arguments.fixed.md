CUDA and HIP input keep a function parameter's default argument as the CrossGL parameter's default, including a default written on an earlier declaration of the function, so every target receives the arguments a call omits. The importers used to drop each default, and nvcc and hipcc rejected the translated call as one argument short. A default CrossTL cannot read as an expression is refused with a diagnostic. HIP input no longer writes a function prototype as a second, empty function, which hipcc rejected as a redefinition.

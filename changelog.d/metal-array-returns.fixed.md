Metal output of functions that return fixed-size arrays compiles: `return x;` of a parameter, structure member or constant, `array<T, N> r = x;`, nested `array<T, N>` initializers, `array<T, N>` locals passed to C-array parameters, C arrays assigned from an array result and generic functions returning their array argument used to be rejected by the Metal compiler or refused (Metal part of #3728).

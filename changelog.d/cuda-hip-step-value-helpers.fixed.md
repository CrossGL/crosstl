CUDA and HIP output now translate a signed `++` or `--` used as a value (`a[k++]`, `while (k++ < n)`, `f(x--)`) from GLSL, HLSL, SPIR-V and Slang sources, whose signed arithmetic wraps, through the wrapping step helpers Metal, DirectX, Slang and SPIR-V already use. CUDA and HIP write the helper's `inout` parameter as a C++ reference (`int& x0`), which updates the argument itself; the increment was refused because these generators were thought to pass `inout` parameters by value.

DirectX and Slang output type the lane argument of WaveReadLaneAt and QuadReadLaneAt as an integer when the value being read is a vector or scalar: `values[i] = WaveReadLaneAt(values[i], (WaveGetLaneIndex() + 1u) % WaveGetLaneCount());` on `vec2` buffers translates without result-context errors in DirectX or lowering refusals in Slang, and Slang output no longer converts wave lane expressions to `float` (#4405).

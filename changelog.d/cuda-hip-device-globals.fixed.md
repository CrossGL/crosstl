CUDA and HIP output declare file-scope vector and array constants as `__device__ const` data with a static brace initializer, CrossGL `device` variables as statically initialized `__device__` variables, and a workgroup variable that a helper function names as a file-scope `__shared__` variable, and refuse a file-scope constant without a static initializer. CUDA output applies its vector operators to constant-buffer vector members, passes the destination of `__stcg`, `__stcs`, `__stwb`, `__stwt` and `__match_all_sync` by address; HIP output writes the cache-hinted stores as plain stores and refuses `__match_all_sync`, which HIP does not declare. nvcc and hipcc used to reject the output of each of these programs.

CUDA and HIP output rename program-scope values whose names C++ reserves in the global namespace (a leading underscore, or a double underscore anywhere) to `global_<name>`, with every reference. SPIR-V disassembly names unnamed block instances `_`, `__0`, `__1`, and CUDA output declared `__device__ int* _;`, which `ptxas` rejected (`Parsing error near '_'`), so nearly every SPIR-V module with an unnamed buffer or uniform block failed to translate to CUDA.

OpenCL C input now rewrites the vector component forms `.hi`, `.lo`, `.even`, `.odd` and `.sN`/`.SN` on vector bases into CrossGL swizzles (`v.hi` is `v.zw`, `v.s01` is `v.xy`, and so on, including as assignment targets), so the DirectX, OpenGL and Metal generators no longer emit forms their compilers reject. A component the vector does not have (`float4.s7`, or the undefined fourth component a 3-component vector pretends to have for `.hi`/`.s3`) now raises a typed diagnostic instead of being copied through (#4517).
